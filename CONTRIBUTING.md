# Contributing to BetterTrade

Thanks for checking out BetterTrade.

This repository is the public product and engineering showcase for the app. The production Flutter application, backend configuration, signing material, store configuration, and commercial release code are intentionally kept private.

## Good things to open an issue for

- broken or outdated links in this repository
- documentation corrections
- accessibility or wording problems in the public showcase
- reproducible bugs you encounter in the released app
- focused product feedback with enough context to understand the workflow
- import or sync problems that can be described without sharing credentials or sensitive trading data

For a product bug, include the app version, device/OS, the relevant workflow, what you expected, and what happened instead. For import or MT5-sync issues, describe the format and failure mode but redact account numbers, tokens, credentials, and personally sensitive trade data.

## Pull requests

Pull requests are welcome for the public showcase itself: documentation fixes, typo corrections, link repairs, and improvements to material published in this repository.

The private production source is not mirrored here, so production feature implementations, backend patches, and release configuration cannot be contributed through this repository.

Keep PRs focused, explain why the change helps, and link a related issue when one exists.

## Security, privacy, and financial data

Do not post API keys, broker credentials, Firebase configuration secrets, account identifiers, purchase receipts, or private trading records in a public issue or pull request.

BetterTrade is a journaling and analytics product, not a broker, signal service, or financial-advice product. Product feedback and bug reports should stay focused on the software and its documented behavior.
